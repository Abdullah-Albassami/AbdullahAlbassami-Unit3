# WebCraft

WebCraft is a responsive website for a fictional website development company.

## Project Structure

- `index.html` — main webpage
- `css/styles.css` — website styling
- `images/` — website images

## Design Choices

- Flexbox is used for the navigation, hero, about, and footer layouts.
- CSS Grid is used for the services section.
- Media queries make the website responsive on smaller screens.
- CSS variables are used for reusable colors.
- Transitions and keyframe animations add simple interactive effects.
- Semantic HTML elements are used throughout the page.
